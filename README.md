# Misi Wira Sejarah

Permainan platformer pendidikan berbahasa Melayu untuk Sejarah Tahun 4.

## Mainkan

Buka `index.html` dengan pelayar moden. Permainan ini tidak memerlukan akaun murid; kemajuan disimpan dalam Local Storage pada peranti dan pelayar yang digunakan.

## Terbitkan untuk organisasi

Workflow `.github/workflows/pages.yml` menerbitkan laman secara automatik ke GitHub Pages setiap kali perubahan dihantar ke cabang `main`. Selepas repo diwujudkan, pilih GitHub Pages sebagai sumber deployment jika diminta. Jika repo awam, organisasi lain boleh membuka pautan Pages tanpa akaun GitHub.

## Fail

- `index.html` — rangka aplikasi dan halaman
- `style.css` — gaya responsif
- `game.js` — permainan, soalan dan simpanan kemajuan

## Kawalan

- Anak panah kiri/kanan: bergerak
- Anak panah atas atau Space: melompat
- Dekati kotak ilmu untuk membuka soalan
- Telefon/tablet: gunakan butang sentuh

## Kandungan

Lima dunia, setiap satu dengan tiga misi, merangkumi Mari Belajar Sejarah, Zaman Air Batu, Zaman Prasejarah, Kerajaan Melayu Awal dan tokoh Kesultanan Melayu Melaka. TP yang dipaparkan ialah anggaran perkembangan permainan, bukan pentaksiran rasmi. Tiada papan pemuka guru atau penyegerakan markah antara peranti dalam versi ini.

## Sumber kurikulum

Kandungan dirangka berdasarkan DSKP KSSR Sejarah Tahun 4 (Semakan 2017). Rujukan: [Perincian DSKP Sejarah Tahun 4](https://ipim.jmm.gov.my/sites/default/files/dockokurikulum/1.%20TAHUN%204_PERINCIAN%20DSKP%20BT.pdf).
